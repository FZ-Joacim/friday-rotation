How to Make Changes

This page lives on GitHub Pages. Changes take about 2 minutes — it's like editing a document, no coding knowledge needed.

1
Go to github.com and sign in to the Flynn Zito account.
2
Open the repository called friday-rotation and click index.html.
3
Click the pencil icon (top right of the file) to open the editor.
4
To add or change a person, find the section marked // ===== EDIT PEOPLE HERE =====. Change inactive to active to add someone (e.g. when Joe gets remote access).
5
For a one-off override, find // ===== EDIT OVERRIDES HERE ===== and add a line like:
'2026-06-12': ['Stefan', 'Cole'],
6
Click Commit changes — the live site updates in about 60 seconds.
Adding the real logo: Upload your logo PNG file alongside index.html in GitHub, then find the logo comment in the file and replace the wordmark div with <img src="logo.png" class="logo-img" />.
